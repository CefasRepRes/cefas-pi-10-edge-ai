# RAPID Plankton
cefas-pi-10-edge-ai is a public release of the internally held repository https://github.com/CefasRepRes/rapid-plankton
Git history has been squashed for security purposes. Previous versions available in the private internal repository are not publicly visible, but the code was originally developed by RobBlackwell (Robert Blackwell).

Realtime Access to Plankton Imager Data (RAPID) is a collection of tools for working locally with data from the Plankton Analytics PI10 instrument.

The software was developed at Cefas with contributions from the National Oceanography Centre and the Alan Turing Institute.


## Repository overview

This repository contains several components used to receive, process, and display plankton imager data in near real time.

### `edge-ai`

A Python application intended to run on an NVIDIA Jetson or similar Linux system. It receives images transmitted over UDP from the PI10, classifies them, and sends summary statistics to a message bus.

### `data/examples`

Example data files generated by the PI10. These are useful for testing `edge-ai` commands while working offline or without the instrument connected.

# To define the actions secret
This allows the repository and therefore github actions to make use of available runner minutes to operate on our blob store.
